## 📖 About StudioSpace

**StudioSpace** is a modern, full-stack web application designed for browsing, listing, and booking creative studio spaces, photography spots, podcast rooms, and meeting facilities. Built with performance and user experience in mind, it provides seamless authentication, responsive interfaces, real-time feedback, and full studio management capability for hosts.

---

## ✨ Key Features

- 🔐 **Secure Authentication:** Social Sign-In (Google OAuth) and Email/Password flow powered by **Better Auth** with JWT session handling.
- 🏢 **Browse & Filter Studios:** Explore studios by categories, rates, location, and interactive search.
- ➕ **Host Dashboard / Manage Listings:** Hosts can list new studios, update existing information via dynamic modals, and remove listings.
- 🎨 **Modern & Responsive UI:** Built with Tailwind CSS, HeroUI/shadcn components, clean typography, and full dark/light theme support.
- ⚡ **Optimized Performance:** Next.js App Router, SSR/SSG dynamic page generation, and optimized image rendering.
- 📱 **Mobile First Design:** Fully responsive layout tailored for mobile, tablet, and desktop views.
